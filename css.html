Fundamentos

Conectar HTML y CSS

Aprender CSS · Conceptos y práctica

CSS describe cómo se presenta el HTML. Enlaza una hoja externa desde head y escribe reglas con selector, propiedad y valor. Un archivo separado permite reutilizar los estilos.

Ejemplo

CSS
/* En head: <link rel="stylesheet" href="estilos.css"> */
body {
  background: #f5f2eb;
  color: #202824;
  font-family: system-ui, sans-serif;
}

Pruébalo tú

Crea estilos.css junto a index.html y enlázalo. Cambia el fondo; si no ocurre nada, revisa la ruta en la pestaña Red del navegador.

Selectores

Aprender CSS · Conceptos y práctica

Un selector de tipo afecta a un elemento, una clase se reutiliza y un selector descendiente busca dentro de otro elemento. Las pseudoclases describen estados como :hover o :focus-visible.

Ejemplo

CSS
p { line-height: 1.6; }
.nota { padding: 1rem; }
.nota a { text-decoration: underline; }
a:focus-visible { outline: 3px solid #166449; }

Pruébalo tú

Añade class="nota" a un párrafo con un enlace. Comprueba qué reglas afectan a cada elemento y llega al enlace con Tab.

Cascada y herencia

Aprender CSS · Conceptos y práctica

Entre reglas normales del mismo origen y capa, la especificidad decide: un id pesa más que una clase y una clase más que un tipo. Si empatan, gana la última. Algunas propiedades como color se heredan; margin no. Evita resolver todo con !important.

Ejemplo

CSS
body { color: #202824; }
.nota { color: #195f47; }
.nota { color: #703b16; } /* Gana por aparecer después */

Pruébalo tú

Inspecciona .nota y busca las reglas tachadas y el color calculado. Quita su color para observar la herencia desde body.

Modelo de caja

Aprender CSS · Conceptos y práctica

padding separa el contenido del borde; margin separa la caja de otras. Con border-box, la anchura incluye relleno y borde. max-width limita el tamaño sin obligar a desbordar una pantalla pequeña.

Ejemplo

CSS
*, *::before, *::after { box-sizing: border-box; }
.tarjeta {
  width: 100%;
  max-width: 32rem;
  padding: 1.5rem;
  border: 1px solid #64736b;
  margin-block: 2rem;
}

Pruébalo tú

Inspecciona el modelo de caja. Cambia padding y margin por separado y observa qué espacio cambia.

Unidades y medidas

Aprender CSS · Conceptos y práctica

rem toma como referencia la letra raíz; em depende del tamaño de letra del elemento, salvo en font-size, donde se refiere al padre. % depende de la propiedad y el contenedor. Usa medidas flexibles y un line-height sin unidad.

Ejemplo

CSS
body { font-size: 1rem; line-height: 1.6; }
main { width: min(70rem, 100% - 2rem); margin-inline: auto; }
h1 { font-size: clamp(2rem, 5vw, 4rem); }

Pruébalo tú

Aumenta el tamaño de texto del navegador y comprueba que no pierdes contenido ni controles.

Tipografía y color

Aprender CSS · Conceptos y práctica

Limita la longitud de las líneas y deja interlineado suficiente. Busca contraste de al menos 4,5:1 para texto normal y 3:1 para texto grande. No comuniques errores solo con color y da una señal clara a los enlaces.

Ejemplo

CSS
body { font-family: system-ui, sans-serif; }
p { max-width: 65ch; line-height: 1.7; }
a { text-decoration: underline; }
a:hover { text-decoration-thickness: 2px; }

Pruébalo tú

Revisa el contraste de un párrafo sobre tu fondo y comprueba que distingues los enlaces sin depender del color.

Distribución y adaptación

Flexbox

Aprender CSS · Conceptos y práctica

Flexbox distribuye elementos en una fila o columna. gap los separa, justify-content actúa en el eje principal y align-items en el transversal. flex-wrap permite saltos cuando falta espacio.

Ejemplo

CSS
.acciones {
  display: flex;
  flex-wrap: wrap;
  gap: 1rem;
  align-items: center;
  justify-content: space-between;
}

Pruébalo tú

Agrupa tres enlaces en .acciones y estrecha la ventana. Cambia justify-content y flex-direction para entender los ejes.

CSS Grid

Aprender CSS · Conceptos y práctica

Grid distribuye contenido en dos dimensiones. minmax establece límites y auto-fit crea las columnas que caben. min(100%, 16rem) evita que la anchura mínima supere el contenedor.

Ejemplo

CSS
.rejilla {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(100%, 16rem), 1fr));
  gap: 1.5rem;
}

Pruébalo tú

Crea varias tarjetas dentro de .rejilla y cambia el ancho de la ventana. Observa cómo se reorganizan.

Diseño adaptable

Aprender CSS · Conceptos y práctica

Empieza con una columna y añade complejidad cuando haya espacio. Las media queries aplican reglas según el entorno. No desactives el zoom ni fijes anchuras que obliguen a desplazar horizontalmente toda la página.

Ejemplo

CSS
.contenido { display: grid; gap: 2rem; }
img { max-width: 100%; height: auto; }
@media (min-width: 50rem) {
  .contenido { grid-template-columns: 1fr 1fr; }
}

Pruébalo tú

Prueba tu página a 320 píxeles y con zoom al 200 %. Revisa navegación, imágenes y palabras largas.

Accesibilidad y práctica

Interacción accesible

Aprender CSS · Conceptos y práctica

No elimines el foco visible sin ofrecer un sustituto claro. Acompaña hover con foco y respeta la preferencia de reducir movimiento. Da a los controles espacio suficiente para pulsarlos.

Ejemplo

CSS
button { min-height: 44px; padding: .75rem 1rem; }
button:focus-visible {
  outline: 3px solid #166449;
  outline-offset: 4px;
}
@media (prefers-reduced-motion: reduce) {
  html { scroll-behavior: auto; }
}

Pruébalo tú

Usa Tab para llegar a un botón y Espacio para activarlo. Comprueba que el foco se distingue del fondo.

Variables CSS

Aprender CSS · Conceptos y práctica

Las propiedades personalizadas guardan valores reutilizables y participan en la cascada. Defínelas en :root para compartirlas o en un componente para limitar su alcance. var acepta un valor de reserva.

Ejemplo

CSS
:root {
  --fondo: #1f2522;
  --texto: #f4f6f5;
  --espacio: 1.5rem;
}
.tarjeta {
  background: var(--fondo);
  color: var(--texto);
  padding: var(--espacio, 1rem);
}

Pruébalo tú

Usa --espacio en dos componentes y cambia su valor en un solo sitio. Observa cómo se actualizan ambos.

Tu primera tarjeta

Aprender CSS · Conceptos y práctica

Revisa las reglas en Estilos y el resultado en Valores calculados. Si algo desborda, revisa anchuras y modelo de caja antes de ocultarlo. Combina tipografía, espacio y distribución en una tarjeta.

Ejemplo

CSS
.tarjeta {
  display: grid;
  gap: 1rem;
  max-width: 28rem;
  padding: 1.5rem;
  border: 1px solid #68796f;
  border-radius: .75rem;
}
.tarjeta h2, .tarjeta p { margin: 0; }

Pruébalo tú

Crea un article con class="tarjeta", un h2, un párrafo y un enlace. Aplica los estilos y comprueba el resultado con teclado y a varios tamaños.
