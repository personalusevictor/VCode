Primeros pasos

Para empezar con una base clara.

¿Qué puedo encontrar en VCode?

VCode reúne explicaciones de HTML y CSS con ejemplos de código para consultar mientras aprendes. En la referencia HTML encontrarás para qué sirve cada elemento, sus atributos principales y formas de utilizarlo.

¿Por dónde empiezo si nunca he hecho una página web?

Empieza por la estructura de un documento: html, head y body. Después añade un encabezado, un párrafo y un enlace. Haz cambios pequeños y observa el resultado en el navegador.

¿Necesito instalar muchas herramientas?

Para un primer documento HTML basta con un editor de texto y un navegador. Guarda el archivo con la extensión .html y ábrelo en el navegador. Un editor de código puede ayudarte con el formato y el cierre de etiquetas.

¿Tengo que memorizar todas las etiquetas?

No hace falta aprenderlas todas de golpe. Practica con las más habituales y consulta las demás cuando las necesites. Entender qué representa cada elemento es más útil que recordar una lista de nombres.

Entender HTML

Conceptos que suelen generar dudas.

¿Qué diferencia hay entre HTML, CSS y JavaScript?

HTML organiza y da significado al contenido. CSS define su presentación: colores, tipografía y distribución. JavaScript permite añadir comportamiento, como filtrar una lista o responder a una acción.

¿Qué diferencia hay entre una etiqueta y un atributo?

Las etiquetas delimitan elementos, como <p>Hola</p>. Los atributos aportan información adicional en la etiqueta de apertura: en <html lang="es">, lang es el atributo y es su valor.

¿Por qué importa usar HTML semántico?

Porque el elemento cuenta qué función tiene el contenido. nav identifica una zona de navegación y main el contenido principal. Elegir el elemento adecuado ayuda a que la estructura resulte comprensible también con tecnologías de asistencia.

¿Cuándo uso un enlace y cuándo un botón?

Usa a para navegar a otro destino. Usa button para ejecutar una acción, como abrir un menú. Que ambos puedan tener un aspecto parecido no cambia su función.

Ponerlo en práctica

Del ejemplo al documento que estás creando.

¿Puedo copiar los ejemplos y modificarlos?

Sí. Puedes utilizar el botón Copiar de la referencia, pegar el fragmento en tu documento y adaptarlo. Prueba a cambiar el texto o un atributo para entender qué efecto tiene cada parte.

¿Los ejemplos son páginas completas?

No siempre. Muchos son fragmentos que se centran en un elemento. Para probarlos, colócalos en el lugar adecuado de un documento HTML: el contenido visible normalmente va dentro de body; los metadatos, en head.

¿Qué reviso si un ejemplo no funciona como esperaba?

Comprueba que hayas guardado el archivo y actualizado el navegador. Revisa las etiquetas de apertura y cierre, las comillas de los atributos y las rutas de imágenes o archivos. Un fragmento puede necesitar otros elementos alrededor para tener sentido.
