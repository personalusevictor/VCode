Preguntas frecuentes

Resuelve tus dudas.

Respuestas breves para comprender mejor HTML y empezar a escribir código con confianza.

¿Qué es HTML?

HTML (HyperText Markup Language) es el lenguaje de marcado que organiza el contenido de una página web mediante elementos o etiquetas.

¿HTML es un lenguaje de programación?

No. HTML es un lenguaje de marcado: describe la estructura y el significado del contenido. CSS aporta la presentación y JavaScript la interactividad.

¿Qué necesito para empezar?

Un editor de texto, un navegador y un archivo con extensión .html. Puedes abrir ese archivo directamente en tu navegador.

¿Cuál es la diferencia entre HTML y CSS?

HTML define la estructura y el contenido (títulos, párrafos, enlaces); CSS define colores, tipografía, espacios y distribución.

¿Qué son los atributos HTML?

Son valores adicionales dentro de la etiqueta de apertura. Por ejemplo, href indica el destino de un enlace, y alt describe una imagen.

¿Para qué sirven las etiquetas semánticas?

Elementos como header, nav, main o article describen el papel del contenido. Facilitan el mantenimiento, la accesibilidad y la comprensión del documento.

¿Qué diferencia hay entre class e id?

class puede compartirse entre varios elementos para aplicar estilos o agruparlos; id identifica un elemento de forma única dentro de la página.

¿Por qué mi formulario no envía correos?

HTML puede construir y validar un formulario, pero para enviar mensajes realmente se necesita un servidor o servicio externo. El formulario de esta web es una demostración local.
