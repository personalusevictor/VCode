Documento

<html>

Raíz del documento

Consultar MDN

Agrupa el documento completo: head contiene metadatos y body el contenido visible. Declara HTML moderno con <!doctype html> antes de la raíz.

Ejemplo

HTML 
<!doctype html>
<html lang="es">
  <head><title>Mi página</title></head>
  <body><h1>Hola</h1></body>
</html>

Atributos principales

Atributos de <html>
Atributo Utilidad
lang Idioma principal, por ejemplo es; permite una pronunciación correcta.

Uso y variantes

Puedes indicar otro lang en un descendiente cuando cambie el idioma. No uses la raíz como contenedor de interfaz.

El ejemplo es una estructura abreviada: añade charset y viewport en producción.

<head>

Metadatos y recursos

Consultar MDN

Reúne información sobre el documento. No representa una sección visible de la página y debe preceder a body.

Ejemplo

HTML 
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Referencia | VCode</title>
</head>

Atributos principales

Atributos de <head>
Atributo Utilidad
id Identificador global; normalmente no es necesario aquí.

Uso y variantes

Contiene title, meta, link y otros metadatos. El contenido de la interfaz pertenece a body.

Incluye un título específico por página.

<meta>

Configuración del documento

Consultar MDN

Declara codificación, descripción y configuración del viewport. Es un elemento vacío: no tiene etiqueta de cierre.

Ejemplo

HTML 
<meta charset="utf-8">
<meta name="description" content="Aprende HTML con ejemplos">
<meta name="viewport" content="width=device-width, initial-scale=1">

Atributos principales

Atributos de <meta>
Atributo Utilidad
charset Usa utf-8 y sitúa la declaración al principio de head.
name Tipo de metadato, como description o viewport.
content Valor del metadato definido por name.

Uso y variantes

charset declara la codificación; name y content expresan metadatos por nombre. http-equiv admite directivas concretas, no reemplaza cualquier cabecera HTTP.

Accesibilidad. No bloquees el zoom con user-scalable=no: permite que cada persona ajuste el tamaño de lectura.

<link>

Relaciones y hojas de estilo

Consultar MDN

Relaciona el documento con un recurso externo. Para estilos, el navegador descarga y aplica el CSS enlazado. Es un elemento vacío.

Ejemplo

HTML 
<link rel="stylesheet" href="assets/css/styles.css">
<link rel="stylesheet" href="print.css" media="print">

Atributos principales

Atributos de <link>
Atributo Utilidad
rel Relación: stylesheet, icon o preload, entre otras.
href Dirección del recurso.
media Condición de medios; por ejemplo print.

Uso y variantes

stylesheet aplica CSS; icon declara un icono. preload anticipa una descarga y necesita un as adecuado; no aplica estilos por sí solo.

Evita precargar recursos sin medir su necesidad.

Estructura

<header>

Introducción y navegación

Consultar MDN

Introduce una página o una sección con su identidad, título o navegación. Puede haber varias cabeceras si pertenecen a contextos diferentes.

Ejemplo

HTML 
<header>
  <a href="index.html">VCode</a>
  <nav aria-label="Principal"><a href="labels.html">Etiquetas</a></nav>
</header>

Atributos principales

Atributos de <header>
Atributo Utilidad
id Destino de un enlace interno.
class Gancho para estilos; no aporta semántica.

Uso y variantes

La cabecera de página suele ser un punto de referencia; una cabecera dentro de article introduce ese artículo. No anides header o footer dentro de header.

No hace falta añadir role="banner" a una cabecera de página nativa.

<nav>

Bloque de navegación

Consultar MDN

Agrupa enlaces importantes para recorrer el sitio o la página. No todos los grupos de enlaces requieren nav.

Ejemplo

HTML 
<nav aria-label="En esta página">
  <a href="#tag-main">Contenido principal</a>
  <a href="#tag-article">Artículos</a>
</nav>

Atributos principales

Atributos de <nav>
Atributo Utilidad
aria-label Nombre accesible cuando hay varias navegaciones.
aria-labelledby Referencia al id de un título visible.

Uso y variantes

Puede contener una lista de enlaces o enlaces directos. Distingue la navegación principal de un índice local con nombres claros.

Usa aria-current="page" en el enlace de la página actual.

<main>

Contenido principal

Consultar MDN

Contiene el contenido dominante de la página. Excluye la navegación y los bloques repetidos comunes a todo el sitio.

Ejemplo

HTML 
<a href="#contenido">Saltar al contenido</a>
<main id="contenido">
  <h1>Referencia HTML</h1>
</main>

Atributos principales

Atributos de <main>
Atributo Utilidad
id Permite un enlace para saltar directamente al contenido.

Uso y variantes

Mantén un único main visible por documento. Una aplicación puede conservar otros main ocultos, pero solo uno debe estar activo.

No anides main dentro de article, aside, footer, header o nav.

<section>

Sección temática

Consultar MDN

Agrupa contenido sobre un mismo tema cuando no existe un elemento más específico. Suele llevar un encabezado que explica su propósito.

Ejemplo

HTML 
<section aria-labelledby="titulo-formularios">
  <h2 id="titulo-formularios">Formularios</h2>
  <p>Recoge datos con controles nativos.</p>
</section>

Atributos principales

Atributos de <section>
Atributo Utilidad
aria-labelledby Asocia la sección con su encabezado visible.
id Identifica la sección para enlaces.

Uso y variantes

Una sección con nombre accesible puede ser un punto de referencia. Usa div si solo necesitas un contenedor de diseño.

No elijas section solo para aplicar márgenes.

<article>

Contenido independiente

Consultar MDN

Representa una unidad que conserva sentido por sí misma: una noticia, una publicación o una ficha de referencia.

Ejemplo

HTML 
<article aria-labelledby="titulo-articulo">
  <h2 id="titulo-articulo">Cómo crear un enlace</h2>
  <p>Usa el elemento a con href.</p>
</article>

Atributos principales

Atributos de <article>
Atributo Utilidad
aria-labelledby Vincula la unidad con su título.

Uso y variantes

Puede tener header y footer propios. Los artículos anidados representan contenido relacionado, como comentarios de una publicación.

La independencia del contenido determina si article es adecuado.

<aside>

Información complementaria

Consultar MDN

Contiene información relacionada de forma indirecta con el contenido principal: un glosario, una nota contextual o recursos.

Ejemplo

HTML 
<aside aria-labelledby="consejo">
  <h2 id="consejo">Antes de empezar</h2>
  <p>Abre las herramientas del navegador.</p>
</aside>

Atributos principales

Atributos de <aside>
Atributo Utilidad
aria-label Nombre del bloque si no hay un título visible.
aria-labelledby Referencia a su encabezado.

Uso y variantes

Puede complementar la página entera o un artículo concreto. Su significado no depende de estar colocado a la derecha o izquierda.

No escondas instrucciones esenciales en un bloque considerado complementario.

<footer>

Información de cierre

Consultar MDN

Incluye autoría, enlaces relacionados o información legal de la página o sección más cercana.

Ejemplo

HTML 
<footer>
  <small>© 2026 VCode</small>
  <a href="contact.html">Contacto</a>
</footer>

Atributos principales

Atributos de <footer>
Atributo Utilidad
id Identificador global opcional.

Uso y variantes

Un footer de página suele ser un punto de referencia; dentro de article cierra ese artículo. No es obligatorio que esté al final de la ventana.

No anides header o footer dentro de footer.

Texto

<h1>

Encabezados de h1 a h6

Consultar MDN

Definen seis niveles de títulos para estructurar el contenido. h1 presenta el tema principal; h2 abre secciones y h3 desarrolla subsecciones.

Ejemplo

HTML 
<h1>Aprender HTML</h1>
<h2>Formularios</h2>
<h3>Etiquetas de los campos</h3>

Atributos principales

Atributos de <h1>
Atributo Utilidad
id Permite enlazar una sección desde un índice.

Uso y variantes

Escoge el nivel por jerarquía, no por tamaño visual. CSS puede cambiar el tamaño sin cambiar la estructura.

Evita saltos de nivel al abrir subsecciones. Una única h1 es una convención clara para esta página.

<p>

Párrafos

Consultar MDN

Representa un párrafo de texto. Admite contenido de fraseo como enlaces o énfasis, pero no listas, tablas ni secciones.

Ejemplo

HTML 
<p>HTML describe la estructura del contenido.</p>
<p>CSS define su presentación visual.</p>

Atributos principales

Atributos de <p>
Atributo Utilidad
lang Idioma específico si difiere del documento.
dir Dirección del texto: ltr, rtl o auto.

Uso y variantes

Usa varios p para ideas separadas. br introduce un salto de línea significativo, no sustituye a los párrafos ni a los márgenes CSS.

Anidación. No introduzcas listas, tablas o secciones dentro de p. El navegador cerrará el párrafo antes de esos elementos.

<a>

Enlaces e hipervínculos

Consultar MDN

Con href permite navegar a otra página, un fragmento, un correo o una descarga. Sin href no representa un hipervínculo.

Ejemplo

HTML 
<a href="#tag-form">Ver formularios</a>
<a href="https://html.spec.whatwg.org/"
   target="_blank" rel="noopener">Estándar HTML (nueva pestaña)</a>

Atributos principales

Atributos de <a>
Atributo Utilidad
href Destino relativo, absoluto o fragmento.
target Contexto de navegación, como _blank.
rel Relación y opciones como noopener.
download Sugiere descargar un recurso, sujeto a restricciones de origen.

Uso y variantes

Usa #id para navegar dentro del documento y mailto: para abrir el cliente de correo. Un botón ejecuta acciones; un enlace cambia de destino.

Escribe un texto que describa el destino. No anides enlaces ni otros controles interactivos.

<strong>

Importancia del texto

Consultar MDN

Marca importancia, seriedad o urgencia. Su significado permanece aunque cambies el peso tipográfico con CSS.

Ejemplo

HTML 
<p><strong>Guarda tus cambios</strong> antes de salir.</p>
<p>Esto es <em>especialmente</em> útil.</p>

Atributos principales

Atributos de <strong>
Atributo Utilidad
class Permite estilos sin alterar su significado.

Uso y variantes

strong comunica importancia; em marca énfasis de la frase. b llama la atención sin añadir importancia y no sustituye a strong en advertencias.

No uses negrita como único medio para transmitir una instrucción importante.

<ul>

Listas y elementos li

Consultar MDN

ul representa una lista cuyo orden no importa. Cada elemento se expresa con li; una lista anidada debe estar dentro de un li.

Ejemplo

HTML 
<ul>
  <li>HTML: estructura</li>
  <li>CSS: presentación</li>
</ul>
<ol start="2">
  <li>Escribe el contenido</li>
  <li>Comprueba el resultado</li>
</ol>

Atributos principales

Atributos de <ul>
Atributo Utilidad
class Define estilos de lista mediante CSS.

Uso y variantes

ol indica un orden significativo y admite start, reversed y type. li admite value cuando pertenece a ol para fijar su número.

No simules listas con guiones y saltos de línea; conserva su semántica nativa.

<pre>

Código y texto preformateado

Consultar MDN

Conserva espacios y saltos de línea. Junto con code representa ejemplos de código; el contenido sigue siendo interpretado como HTML si no se escapa.

Ejemplo

HTML 
<pre><code>&lt;p&gt;Hola, mundo&lt;/p&gt;</code></pre>

Atributos principales

Atributos de <pre>
Atributo Utilidad
tabindex Con 0 permite enfocar un bloque desplazable cuando sea necesario.

Uso y variantes

pre conserva formato; code identifica un fragmento de código. Para una palabra dentro de una frase basta con code.

Código literal. Escapa < como &lt; y & como &amp; en el código fuente para mostrar las etiquetas sin que el navegador las interprete.

Multimedia

<img>

Imágenes con alternativa textual

Consultar MDN

Incrusta una imagen y es un elemento vacío. El texto alternativo debe comunicar su función en el contexto, no limitarse a describir píxeles.

Ejemplo

HTML 
<figure>
  <img src="diagrama.png" alt="HTML define estructura; CSS, presentación"
       width="640" height="360" loading="lazy">
  <figcaption>Separación de responsabilidades.</figcaption>
</figure>

Atributos principales

Atributos de <img>
Atributo Utilidad
src URL de la imagen.
alt Alternativa textual; vacío si es puramente decorativa.
width / height Dimensiones intrínsecas para reservar espacio.
loading lazy para imágenes fuera de la vista inicial.
srcset / sizes Selección de recursos adaptados al tamaño y densidad.

Uso y variantes

Usa picture cuando necesites dirección artística o formatos alternativos. figure con figcaption asocia una leyenda visible.

No apliques lazy a la imagen principal si retrasa su carga. Una leyenda no sustituye automáticamente a alt.

<video>

Vídeo nativo

Consultar MDN

Reproduce vídeo y puede ofrecer varias fuentes. Incluye controles y alternativas para que el contenido no dependa exclusivamente de la imagen o del sonido.

Ejemplo

HTML 
<video controls preload="metadata" width="640">
  <source src="leccion.mp4" type="video/mp4">
  <track kind="captions" src="leccion-es.vtt"
         srclang="es" label="Español" default>
  Tu navegador no reproduce este vídeo.
</video>

Atributos principales

Atributos de <video>
Atributo Utilidad
controls Muestra los controles nativos.
poster Imagen previa a la reproducción.
preload Sugerencia de carga: none, metadata o auto.
muted / loop Silencio inicial y repetición.

Uso y variantes

source permite ofrecer formatos alternativos. track con kind="captions" ofrece subtítulos de sonidos y diálogo; añade una transcripción accesible.

Evita autoplay: puede molestar, consumir datos y estar bloqueado por el navegador.

Tablas

<table>

Datos tabulares

Consultar MDN

Relaciona datos por filas y columnas. caption identifica la tabla; thead y tbody agrupan filas tr y las celdas se expresan con th o td.

Ejemplo

HTML 
<table>
  <caption>Elementos por función</caption>
  <thead><tr><th scope="col">Elemento</th><th scope="col">Uso</th></tr></thead>
  <tbody><tr><th scope="row">a</th><td>Navegación</td></tr></tbody>
</table>

Atributos principales

Atributos de <table>
Atributo Utilidad
id Identificador de la tabla.
class Gancho para presentación; usa CSS en lugar de border.

Uso y variantes

th identifica encabezados y admite scope="col" o "row". colspan y rowspan extienden celdas. Para tablas complejas pueden hacer falta id y headers.

No utilices tablas para maquetar páginas. Mantén asociaciones claras entre encabezados y datos.

Formularios

<form>

Envío de datos

Consultar MDN

Agrupa controles para enviar datos a un destino. Los controles deben tener name para aportar normalmente su valor al envío.

Ejemplo

HTML 
<form action="/buscar" method="get">
  <label for="consulta">Buscar</label>
  <input id="consulta" name="q" type="search">
  <button type="submit">Buscar</button>
</form>

Atributos principales

Atributos de <form>
Atributo Utilidad
action URL que procesa los datos.
method get o post; dialog cierra un diálogo en su contexto.
enctype multipart/form-data para subir archivos con post.
autocomplete Sugerencia de autocompletado: on u off.

Uso y variantes

get añade datos a la URL y sirve para consultas; post envía datos en el cuerpo. post no cifra: utiliza HTTPS. No se pueden anidar formularios.

Validación. Comprueba siempre los datos en el servidor. Las restricciones del navegador se pueden omitir y no protegen por sí solas el procesamiento del formulario.

<label>

Nombre de un control

Consultar MDN

Asocia un texto visible con un control. Pulsar la etiqueta facilita el enfoque o la activación y aumenta el área de interacción.

Ejemplo

HTML 
<label for="correo">Correo electrónico</label>
<input id="correo" name="email" type="email"
       aria-describedby="ayuda-correo">
<small id="ayuda-correo">Te enviaremos la confirmación.</small>

Atributos principales

Atributos de <label>
Atributo Utilidad
for Debe coincidir exactamente con el id de un control etiquetable.

Uso y variantes

Puedes envolver el control en label o asociarlo mediante for. Un campo suele tener una etiqueta visible incluso si hay texto de ayuda.

placeholder desaparece al escribir y no sustituye a label. Evita enlaces y botones dentro de una etiqueta.

<input>

Controles según el tipo

Consultar MDN

Crea controles de una sola entrada o selección. Es vacío; type cambia tanto su interfaz como las reglas de validación y los atributos aplicables.

Ejemplo

HTML 
<label for="edad">Edad</label>
<input id="edad" name="edad" type="number" min="18" max="120" required>
<label><input type="checkbox" name="boletin" value="si"> Recibir novedades</label>

Atributos principales

Atributos de <input>
Atributo Utilidad
type text, email, number, checkbox, radio, file y otros.
name / value Nombre y valor de envío.
required Exige un valor válido cuando el tipo lo admite.
min / max / step Límites e incrementos en tipos compatibles.
autocomplete Propósito del dato: email, name, etc.

Uso y variantes

radio con el mismo name forma un grupo; checkbox permite opciones independientes. disabled excluye el control del envío; readonly mantiene su valor y solo se admite en ciertos tipos.

Atributos booleanos. required="false" también activa required. Para desactivarlo, elimina el atributo.

<button>

Acciones y envío

Consultar MDN

Crea un botón nativo operable con teclado. Su texto debe explicar la acción; puede contener iconos y texto, pero no otros controles interactivos.

Ejemplo

HTML 
<button type="submit">Guardar cambios</button>
<button type="button" aria-expanded="false"
        aria-controls="panel">Mostrar opciones</button>

Atributos principales

Atributos de <button>
Atributo Utilidad
type submit envía, button ejecuta una acción y reset restablece.
disabled Impide su interacción y lo excluye del envío.
name / value Dato enviado cuando ese botón inicia el envío.

Uso y variantes

Dentro de un formulario, declara siempre type para evitar envíos accidentales. Fuera de él, una acción personalizada necesita JavaScript.

aria-expanded debe actualizarse cuando se abre el panel; el atributo por sí solo no implementa la interacción.

<textarea>

Texto de varias líneas

Consultar MDN

Recoge texto libre de varias líneas. El valor inicial se escribe entre sus etiquetas y no en un atributo value.

Ejemplo

HTML 
<label for="mensaje">Tu mensaje</label>
<textarea id="mensaje" name="mensaje" rows="5"
          maxlength="2000" required></textarea>

Atributos principales

Atributos de <textarea>
Atributo Utilidad
name Clave usada al enviar el formulario.
rows / cols Tamaño inicial orientativo, ajustable con CSS.
minlength / maxlength Límites de longitud.
required Impide enviar el campo vacío.

Uso y variantes

readonly permite seleccionar y enviar el texto sin editarlo; disabled impide interacción y envío. wrap modifica el ajuste de líneas y, con hard, el envío.

Permite redimensionar el campo y muestra instrucciones fuera del placeholder.

<select>

Selección de opciones

Consultar MDN

Ofrece opciones predefinidas con option. optgroup agrupa opciones relacionadas mediante su atributo label.

Ejemplo

HTML 
<label for="nivel">Nivel</label>
<select id="nivel" name="nivel" required>
  <option value="">Elige tu nivel</option>
  <option value="inicial">Inicial</option>
  <option value="medio">Intermedio</option>
</select>

Atributos principales

Atributos de <select>
Atributo Utilidad
name Clave del dato enviado.
multiple Permite varias opciones.
size Número orientativo de opciones visibles.
required Requiere una selección válida.

Uso y variantes

En option, value define el dato enviado y selected la selección inicial. Un select multiple puede enviar varias entradas con el mismo name.

No cambies de página automáticamente al seleccionar; ofrece un botón si la elección necesita confirmación.

Interacción

<details>

Contenido desplegable

Consultar MDN

Ofrece un bloque que la persona puede abrir o cerrar sin JavaScript. Su primer summary aporta el título visible del control.

Ejemplo

HTML 
<details>
  <summary>¿Qué diferencia hay entre HTML y CSS?</summary>
  <p>HTML estructura el contenido y CSS lo presenta.</p>
</details>

Atributos principales

Atributos de <details>
Atributo Utilidad
open Presente para mostrar el contenido inicialmente.
name Agrupa desplegables para que solo uno del grupo permanezca abierto en navegadores compatibles.

Uso y variantes

Sin open comienza cerrado. summary actúa como disparador y no necesita role="button" ni un aria-expanded gestionado manualmente.

No ocultes mensajes de error esenciales en un desplegable cerrado. Comprueba compatibilidad de name si dependes del acordeón exclusivo.
