Diccionario HTML

Las etiquetas.

Consulta qué hace cada elemento, qué atributos suele utilizar y cómo se escribe. Usa el buscador o filtra por categorías.

Estructura

<html>

Elemento raíz del documento HTML.

Atributos principales: lang

Define el idioma del contenido.

Ejemplo de uso
<html lang="es">...</html>
Estructura

<head>

Contiene metadatos y enlaces a recursos, no contenido visible.

Atributos principales: —

No tiene atributos específicos habituales; admite atributos globales.

Ejemplo de uso
<head><title>Mi web</title></head>
Estructura

<title>

Establece el título que aparece en la pestaña del navegador.

Atributos principales: —

No tiene atributos específicos habituales.

Ejemplo de uso
<title>Mi página</title>
Estructura

<meta>

Proporciona metadatos como la codificación o la descripción.

Atributos principales: charset, name, content

Permiten definir la codificación y el tipo de metadato.

Ejemplo de uso
<meta charset="UTF-8">
Estructura

<body>

Agrupa todo el contenido visible de la página.

Atributos principales: —

Admite atributos globales como class e id.

Ejemplo de uso
<body><h1>Hola</h1></body>
Estructura

<header>

Define una cabecera de página o de sección.

Atributos principales: id, class

Ayudan a identificarla y aplicar estilos.

Ejemplo de uso
<header><h1>Mi sitio</h1></header>
Estructura

<nav>

Identifica un bloque de navegación.

Atributos principales: aria-label

Permite nombrar la navegación para lectores de pantalla.

Ejemplo de uso
<nav aria-label="Principal"><a href="/">Inicio</a></nav>
Estructura

<main>

Marca el contenido principal único de la página.

Atributos principales: id

Permite crear enlaces para saltar al contenido.

Ejemplo de uso
<main id="contenido">Texto principal</main>
Estructura

<section>

Agrupa contenido relacionado temáticamente.

Atributos principales: aria-labelledby

Asocia la sección con su encabezado.

Ejemplo de uso
<section><h2>Noticias</h2><p>...</p></section>
Estructura

<article>

Representa contenido independiente y reutilizable.

Atributos principales: class

Permite aplicar un diseño de tarjeta u otro estilo.

Ejemplo de uso
<article><h2>Entrada</h2><p>Resumen</p></article>
Estructura

<footer>

Identifica el pie de página o de una sección.

Atributos principales: class

Permite compartir un estilo entre varios pies.

Ejemplo de uso
<footer><small>© 2026</small></footer>
Texto

<h1>

Encabezado principal; h2 a h6 crean niveles subordinados.

Atributos principales: id

Sirve para enlazar directamente a una sección.

Ejemplo de uso
<h1>Aprender HTML</h1><h2>Primer paso</h2>
Texto

<p>

Representa un párrafo de texto.

Atributos principales: class

Permite aplicar diferentes estilos de párrafo.

Ejemplo de uso
<p class="intro">Mi primer párrafo.</p>
Texto

<a>

Crea enlaces a otras páginas o ubicaciones.

Atributos principales: href, target, rel

Define el destino y cómo abrirlo; usa rel="noopener" con nuevas pestañas.

Ejemplo de uso
<a href="https://developer.mozilla.org/" target="_blank" rel="noopener">MDN</a>
Texto

<span>

Agrupa texto en línea sin significado semántico propio.

Atributos principales: class, style

Permite aplicar estilos a una palabra concreta.

Ejemplo de uso
<p>Palabra <span style="color:teal">destacada</span></p>
Texto

<strong>

Indica importancia especial en el texto.

Atributos principales: class

Permite personalizar el énfasis visual.

Ejemplo de uso
<p><strong>Importante:</strong> guarda los cambios.</p>
Texto

<ul>

Crea una lista sin orden numérico.

Atributos principales: class

Sirve para cambiar viñetas o espaciado con CSS.

Ejemplo de uso
<ul><li>HTML</li><li>CSS</li></ul>
Texto

<ol>

Crea una lista ordenada.

Atributos principales: start, reversed, type

Cambian el inicio, sentido o estilo de numeración.

Ejemplo de uso
<ol start="3"><li>Tercer paso</li></ol>
Texto

<li>

Representa un elemento dentro de una lista.

Atributos principales: value

En listas ordenadas, puede ajustar su número.

Ejemplo de uso
<ol><li value="4">Cuarto</li></ol>
Multimedia

<img>

Inserta imágenes en el documento.

Atributos principales: src, alt, width, height, loading

Define el archivo, texto alternativo, dimensiones y carga diferida.

Ejemplo de uso
<img src="foto.jpg" alt="Paisaje" width="300" loading="lazy">
Multimedia

<audio>

Incorpora reproducción de sonido.

Atributos principales: controls, autoplay, loop, preload

Muestra controles y configura la reproducción.

Ejemplo de uso
<audio controls src="sonido.mp3">Tu navegador no admite audio.</audio>
Multimedia

<video>

Incorpora reproducción de vídeo.

Atributos principales: controls, poster, width, muted

Controla la interfaz, imagen de portada y reproducción.

Ejemplo de uso
<video controls width="320" poster="portada.jpg"><source src="clip.mp4" type="video/mp4"></video>
Formularios

<form>

Agrupa controles que recogen datos del usuario.

Atributos principales: action, method

Indican a dónde y cómo enviar la información.

Ejemplo de uso
<form action="/enviar" method="post">...</form>
Formularios

<label>

Asocia un texto descriptivo a un campo.

Atributos principales: for

Vincula la etiqueta con el id del campo.

Ejemplo de uso
<label for="nombre">Nombre</label>
Formularios

<input>

Permite introducir datos de distintos tipos.

Atributos principales: type, name, required, placeholder

Establecen el dato esperado, la clave y la validación.

Ejemplo de uso
<input type="email" name="correo" required>
Formularios

<textarea>

Permite escribir textos de varias líneas.

Atributos principales: name, rows, maxlength

Configuran la clave, altura y longitud máxima.

Ejemplo de uso
<textarea name="mensaje" rows="4"></textarea>
Formularios

<button>

Crea un botón interactivo.

Atributos principales: type, disabled

Define si envía formularios o ejecuta una acción.

Ejemplo de uso
<button type="submit">Enviar</button>
Formularios

<select>

Crea un desplegable para elegir opciones.

Atributos principales: name, required, multiple

Controlan el dato y la selección requerida o múltiple.

Ejemplo de uso
<select name="nivel"><option>Inicial</option></select>
