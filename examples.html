Una página desde cero

Define el idioma, los metadatos y el contenido visible de un documento.

Ver referencia ↗
HTML
<!doctype html>
<html lang="es">
  <head>
    <meta charset="utf-8">
    <meta name="viewport"
      content="width=device-width, initial-scale=1">
    <title>Mi primera página</title>
  </head>
  <body>
    <h1>Hola, mundo.</h1>
    <p>Mi primera página empieza aquí.</p>
  </body>
</html>

Ordenar una lista de pasos

Utiliza una lista ordenada cuando la secuencia de las acciones importa.

Ver referencia ↗
HTML
<section aria-labelledby="pasos-titulo">
  <h2 id="pasos-titulo">Tu primera página</h2>
  <ol>
    <li>Crea un archivo llamado index.html.</li>
    <li>Añade un título y un párrafo.</li>
    <li>Guarda el archivo.</li>
    <li>Ábrelo en el navegador.</li>
  </ol>
</section>

Navegar dentro de una página

Relaciona el destino de un enlace con el id de una sección. Prueba los enlaces en el resultado.

Ver referencia ↗
HTML
<nav aria-label="Secciones del ejemplo">
  <a href="#aprender">Aprender</a>
  <a href="#practicar">Practicar</a>
</nav>
<section id="aprender">
  <h2>Aprender</h2>
  <p>Conoce los elementos de HTML.</p>
</section>
<section id="practicar">
  <h2>Practicar</h2>
  <p>Modifica un ejemplo y observa qué cambia.</p>
</section>
Resultado

Una tarjeta con significado

Agrupa un contenido que puede entenderse de forma independiente con article.

Ver referencia ↗
HTML
<article>
  <p><small>GUÍA DE HTML</small></p>
  <h2>Aprende a tu ritmo</h2>
  <p>Un elemento, un ejemplo y una idea nueva
    para poner en práctica.</p>
  <footer>
    <p><strong>Nivel:</strong> primeros pasos</p>
  </footer>
</article>
Resultado

Un formulario con etiquetas claras

Asocia cada label con su campo. Puedes escribir y usar Limpiar para restablecer el formulario.

Ver referencia ↗
HTML
<form>
  <fieldset>
    <legend>Datos de contacto</legend>
    <label for="nombre">Nombre</label>
    <input id="nombre" name="nombre" type="text"
      autocomplete="name">

    <label for="correo">Correo electrónico</label>
    <input id="correo" name="correo" type="email"
      autocomplete="email">
  </fieldset>
  <button type="reset">Limpiar</button>
</form>
Resultado

Comparar información en una tabla

Da un título a los datos e identifica los encabezados de cada columna con scope.

Ver referencia ↗
HTML
<table>
  <caption>Elementos para empezar</caption>
  <thead>
    <tr>
      <th scope="col">Elemento</th>
      <th scope="col">Para qué sirve</th>
    </tr>
  </thead>
  <tbody>
    <tr><td>h1</td><td>Título principal</td></tr>
    <tr><td>p</td><td>Párrafo de texto</td></tr>
    <tr><td>a</td><td>Enlace a un destino</td></tr>
  </tbody>
</table>
Resultado

Mostrar información bajo demanda

Details y summary crean un desplegable nativo. Ábrelo y ciérralo en el resultado.

Ver referencia ↗
HTML
<details>
  <summary>¿Qué significa HTML?</summary>
  <p>HTML es un lenguaje de marcado que define
    la estructura y el significado del contenido
    de una página web.</p>
</details>
