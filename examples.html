Aprender haciendo

Del código a la pantalla.

Compara el HTML de la izquierda con la página real de la derecha. Los ejemplos se muestran en una vista aislada dentro del navegador.

Estructura básica

Un título, un párrafo y una llamada a la acción.

Código HTML
<!DOCTYPE html>
<html lang="es">
<head><meta charset="UTF-8"><title>Ejemplo</title></head>
<body style="font-family:Arial;padding:14px">
  <h1>¡Hola, HTML!</h1>
  <p>Esta es mi primera página.</p>
  <a href="https://developer.mozilla.org/" target="_blank" rel="noopener">Aprender más</a>
</body></html>
Resultado visual

Tarjeta con CSS en línea

El atributo style cambia directamente el aspecto de un elemento (CE2.2).

Código HTML
<!DOCTYPE html>
<html lang="es"><head><meta charset="UTF-8"></head>
<body style="font-family:Arial;padding:16px">
  <article style="border:2px solid teal;border-radius:12px;padding:16px;background:#ecffff">
    <h2 style="color:teal">Mi tarjeta</h2>
    <p>Un ejemplo visual con estilos directos.</p>
  </article>
</body></html>
Resultado visual

Formulario sencillo

Etiquetas asociadas, campos obligatorios y botón de envío.

Código HTML
<!DOCTYPE html>
<html lang="es"><head><meta charset="UTF-8"></head>
<body style="font-family:Arial;padding:14px">
  <form onsubmit="event.preventDefault();alert('Ejemplo: formulario validado')">
    <label for="email">Tu correo:</label><br>
    <input id="email" type="email" required><br><br>
    <button type="submit">Comprobar</button>
  </form>
</body></html>
Resultado visual

Listas y contenido semántico

Una lista ordenada dentro de una sección con título.

Código HTML
<!DOCTYPE html>
<html lang="es"><head><meta charset="UTF-8"></head>
<body style="font-family:Arial;padding:14px">
  <section><h2>Cómo empezar</h2>
    <ol><li>Aprende las etiquetas.</li><li>Escribe HTML.</li><li>Abre tu página.</li></ol>
  </section>
</body></html>
